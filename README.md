# SVGO Website

A site powered by Docusaurus to host the SVGO documentation.

This project is responsible for:

- Maintaining all frontend code for SVGO.dev.
- Extracting and parsing the documentation from [svg/svgo](https://github.com/svg/svgo) via the JS API and JSDocs.
- Orchestrating the localization workflow—the svgo repository only includes the source documentation (English).

## SVG Optimizer

If you're looking for the library and CLI application to optimize SVGs, see [SVGO](https://github.com/svg/svgo).
